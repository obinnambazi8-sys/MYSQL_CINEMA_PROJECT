# MySQL Patient Database Project

## Overview

This project demonstrates my practical knowledge of MySQL and SQL through the creation and manipulation of a patient database.

The project includes two main tables:

* `patients`
* `admissions`

I created the database, designed the tables, inserted sample data, and wrote SQL queries to retrieve, filter, update, and analyse the data.

## Example Queries

The project answers questions such as:

* Which patients are male?
* Which patients have no recorded allergies?
* Which patients have first names beginning with `C`?
* Which patients fall within a specific weight range?
* How many patients were born in 2010?
* Which patient has the greatest height?
* How many admissions are recorded?
* Which patients were admitted and discharged on the same day?
* Which cities are located in province `NS`?
* Which cities start with a vowel?

## Purpose

This project is part of my journey toward becoming a Cloud Security Engineer.
